# July 2026 ECG Dataset Catalog Update

**Review date:** July 29, 2026  
**Review window:** March 13-July 29, 2026, with a retrospective search for older omissions

This review includes reusable human or synthetic ECG waveforms, images, or annotations, including multimodal datasets with a reusable ECG channel. Public downloads and clearly documented registration or credentialing routes were accepted. Paper-only datasets, feature-summary-only releases, and animal datasets were excluded.

## Hyperlink Audit

Every HTTP(S) URL in `README.md` was checked on July 29, 2026. Official dataset records were preferred over mirrors. Redirects were followed, and access-controlled sources were also checked against their official landing-page metadata.

The following issues remain visible rather than being silently removed:

- The repository advertises an MIT license, but no local `LICENSE` file exists. The badge target is retained pending maintainer confirmation.
- The official CPSC 2021 site timed out repeatedly. Its URL is retained and labeled unavailable because no authoritative replacement was found.
- The ECGtizer GitHub organization returns 404. The entry is retained and labeled unavailable pending maintainer review.
- GitHub Discussions is not enabled for the repository. The link is retained and labeled accordingly.
- The Star History page resolves, but its embedded SVG service returned a server error during the audit.
- Some valid publisher and archive pages reject automated requests or return anti-bot responses; these were verified through their official metadata or browser-accessible landing pages instead.

## Review Recommended for these datasets

No existing dataset entry was removed, merged, or substantially renamed. The following pre-existing entries need a maintainer decision before any larger change:

- **CODE-II:** the cited paper describes a 2.7-million-record cohort, but public redistribution may be limited to the smaller CODE-II-open subset. Confirm the intended scope before changing the existing “Public” label or counts.
- **OpenECG** and **Heartcare-220K:** the cited papers describe datasets, but this review did not find a clearly documented public waveform download or credentialed access route. Confirm availability before retaining “Public.”
- **UVA ECG:** the entry says “Request Access” but provides no official access URL.
- **PTB-XL-Image-17K:** the associated paper describes a 17,271-image derivative, but the cited Zenodo DOI and project repository were unavailable during verification. It was not added pending a valid public release URL.
- Several legacy entries contain counts or licenses that differ slightly across versions. These were not broadly rewritten because the requested update prohibits substantive changes to existing entries without explicit approval.
